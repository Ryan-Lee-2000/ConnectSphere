and brought level with main `89f7611` (after SPL-109 and SPL-110) for QA.

| AC | Implementation |
| --- | --- |
| 1 | `equipment_requirements.add_equipment_requirement` notifies when a catalogue line is added. `_record_change` calls `_notify_technical_support_of_change` for every recorded change and removal: reviewed fields only (type, quantity, dates, notes), mapping an unmapped line counts as recorded, unmapped lines notify nobody. `_notify_technical_support` writes the message. |
| 2 | `event_cancellation.cancel_event` sends one notice per cancelled event, only when `_release_equipment` released units. |
| 3 | `notifications.add_technical_support_notices` reads active Technical Support Staff from server-owned role assignments. |
| 4 | Every notice is written in the action's own transaction, so a refusal or rollback leaves none. The dedupe key names the source row (new line, change-history row or event), backed by the existing unique key on (recipient, dedupe key). |
| 5 | `notifications._event_link` sends `technical_` notices to `/workspace/equipment-review-queue`; `Notifications.tsx` accepts that link. |
