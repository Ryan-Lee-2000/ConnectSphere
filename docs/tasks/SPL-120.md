# SPL-120 — View the registration list for an event an Event Coordinator manages

## User outcome

As an Event Coordinator, I want to view the registration list for an event I manage so that I can
brief venue staff on numbers.

## Acceptance criteria

1. The registration list is available for assigned events only.
2. It shows the same information as CS-E19-S6 / SPL-119.
3. It is accessible from the assigned-event page.

## Agreed scope

- Keep SPL-120 as its own story and API access boundary rather than folding it into SPL-119.
- Reuse SPL-119's shared registration-list serializer and attendee-list interface.
- Authorise from the trusted current coordinator assignment. A missing event and an event assigned
  to another coordinator return the same generic not-found response.
- Show the list directly on the existing assigned-event detail page.
- Preserve SPL-119's active count/capacity, attendee fields, withdrawn-registration grouping,
  disabled-registration explanation, empty states, deterministic ordering and no-export boundary.
- Add no write operation, database migration or new attendee field.

## Interfaces

`GET /api/event-requests/assigned/{event_request_id}/registrations`

The response uses the existing `registration_list` contract from SPL-119: `enabled`, `capacity`,
`registered_count`, `registered` and `withdrawn`. Each attendee remains limited to `id`, `name`,
`email`, `contact_number` and `special_requirements`.

## Dependencies

- SPL-119 is complete and supplies the shared read model and interface.
- Existing coordinator assignment scoping supplies the record-level authorisation boundary.

## Exclusions

- Exporting or downloading registrations.
- Editing or withdrawing attendee registrations.
- Changing registration settings.
- Sharing registration information with Venue Staff through a new account view.
- Database or deployment configuration changes.
