# SPL-141 — Request changes to equipment requirements

Sprint 4 · 2 points · Build scope

## Acceptance criteria

1. The change request form (SPL-111) lets the organiser propose adding, changing the quantity or technical notes of, or removing an equipment requirement line for a submitted event.
2. Each equipment proposal is a separate change request item showing the current line (type, quantity, notes) and the proposed value.
3. Quantity must be a positive whole number; an unknown equipment type or an empty request is refused with a clear message, and nothing is saved.
4. Only the organiser's own organisation's submitted events can be changed; drafts, Cancelled and Completed events are refused.
5. Submitting does not change the equipment lines or reservations; SPL-112 applies accepted items.

Source: https://clivelim01-1787647390567.atlassian.net/browse/SPL-141

## Approved interpretation

- Retain SPL-111 owner-only submission, allowed statuses (Under Review, Planning, Confirmed), one pending request per event and a reason per item. Same-organisation colleagues do not gain submission rights.
- Additions select an existing catalogue type. Existing unmapped/free-text lines can have quantity/notes changed or be removed without first mapping them. Changing an existing line's type is outside this story; propose removal/addition instead.
- SPL-112 applies accepted items; SPL-113 communicates outcomes. This story only captures proposals.
